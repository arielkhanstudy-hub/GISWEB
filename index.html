Fitur & Arsitektur WebGIS Local:

WebGIS Local dirancang fleksibel untuk memvisualisasikan data geospasial acuan maupun menambahkan data geospasial kustom secara manual tanpa batas:

  • Input / Upload Data Manual: Mendukung berkas SHP (.zip), Geodatabase ESRI (.zip GDB), GeoPackage (.gpkg), KML, KMZ, GeoJSON, CSV (titik koordinat), GPX, DXF, dan MapInfo TAB dengan konversi otomatis ke GeoJSON.
  • Layer Bawaan Lengkap: Disertai 5 layer tematik acuan (Administrasi, Jalan, Sungai, Toponim Fasilitas, Tutupan Lahan).
  • Integrasi Layanan WMS Terverifikasi: Menghubungkan OGC WMS Radar Cuaca (IEM NEXRAD), Citra Satelit Real-time (NASA GIBS MODIS), dan Peta Terbuka Mundialis OSM.
  • Manajemen Z-Index Terstruktur: Menggunakan Leaflet Custom Panes agar titik dan garis selalu berada di atas layer poligon.
  • Fitur Analisis & Interaksi: Buffer spasial instan, pencarian fitur, tabel data atribut real-time dengan filter cepat, serta ekspor CSV.
